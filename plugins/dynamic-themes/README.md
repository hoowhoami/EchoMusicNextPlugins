# 动态主题

包含秋日枫叶、幻彩、金丝带、杨柳依依、旋转摩天轮。导入生成的
`dynamic-themes-1.0.0.echomod` 并启用后，在主题中心选择具体主题；启用插件不会自动切换主题。

幻彩和金丝带使用实时 GPU 着色器，随窗口尺寸绘制；枫叶与精灵分层由 Qt Quick
动画驱动。软件渲染时两款着色器主题显示静态海报。

“外观调整 → 插件专属设置”可关闭动态效果或调整 0.5–2 倍速度，每款主题独立保存。
宿主减少动效优先。窗口隐藏、最小化、背景完全透明、切换主题或停用插件时由宿主释放背景组件。

构建：

```sh
ECHO_QSB=/absolute/Qt/6.12.0/bin/qsb npx echo-plugin build plugins/dynamic-themes
```
