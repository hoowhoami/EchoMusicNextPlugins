# Folia 歌词插件（开发中）

用于 EchoMusicNext 的 Folia 歌词样式合集，支持单包切换样式和外观设置。

## 构建

在 EchoMusicNextPlugins 仓库根目录执行：

```sh
npm ci
npm run build:folia
```

安装包输出到 `dist/folia-lyrics-skin-1.0.3.echomod`。发布准备还需[完整原生着色器缓存](../../docs/graphics.md#原生着色器预编译)。
