# 频谱可视化

正式插件，参考 EchoMusicPlugins/spectrum-visualizer。使用播放器实际输出后的PCM，不创建音频播放实例，不改音量，不生成模拟音频帧。

- 柱状、波形、混合、雾状、中心频谱五种模式；主题/极光/余烬/冰川/单色配色。
- 播放栏背景、Mini播放器、歌词控件上方独立启用；默认仅歌词区域显示，与旧插件一致。
- 帧率、频带、FFT、平滑、刻度、填充、透明度、歌词高度、背景与雾状/中心参数。
- 设置通过类型化命令持久化在安装私有SQLite；多处绘制共用设置和宿主一次频谱分析。区域隐藏、最小化、关闭、停用均释放订阅和完整绘制实例。
- 雾状使用原三层云形路径、Qt MultiEffect模糊与screen合成；中心频谱保留镜像、升降插值与边缘渐隐。
- 五种模式使用Qt Quick Shapes的CurveRenderer提交原有矢量路径，光晕/模糊及边缘遮罩在GPU合成，不使用Canvas.Image逐帧栅格位图。普通柱状/波形随新音频帧更新，雾状流动和中心攻防插值沿用设置帧率。

HDR选项在宿主未提供graphics.hdr时禁用并说明原因，延续旧插件的SDR回退；不声称此版本提供HDR输出。

构建：仓库根执行npm run build；生成dist/spectrum-visualizer-1.0.0.echomod。打开插件管理面板安装，点插件设置选择显示位置；无需安装其它示例依赖。SDK与插件版本保持1.0.0。

shaders下的qsb由Qt6.12 qsb离线生成（GLSL100es/120/150、HLSL50、MSL12），插件运行时无需编译器。修改frag时用相同参数重新生成。原绘制数学和图标的MIT版权见LICENSE，保留原作者声明。
