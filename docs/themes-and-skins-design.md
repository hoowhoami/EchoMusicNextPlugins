# 主题、完整播放页皮肤与Mini设计

本文件保留职责设计；已接入的主题/完整皮肤/Mini及播放上下文入口、配置和呈现作用域见[外观文档](appearance.md)。宿主导出的feature目录仍是能力协商依据，不能将设计目标当作三端验收结论。

主题与完整播放页皮肤均以EchoMusic当前有效API和产品入口为基线，使用Qt Quick重建，不运行Vue、DOM或CSS。用户选择保存在宿主已有主题/歌词外观服务，插件仅贡献候选与资源。

| 能力       | 主题                                                   | 完整播放页皮肤                                                              | Mini                                              |
| ---------- | ------------------------------------------------------ | --------------------------------------------------------------------------- | ------------------------------------------------- |
| 注册/入口  | 原主题中心，注册不自动使用                             | 原换肤抽屉，注册不自动使用                                                  | 跟随当前主题，无第二份主题选择                    |
| 配色       | light/dark语义token，floating独立可读颜色组            | 默认读取统一主题，可提供自己的完整视觉                                      | 使用主题的mini专属覆盖，未提供时从统一语义值回退  |
| 自定义呈现 | 背景、侧栏、播放栏装饰及QML动效/shader                 | 接管整个页面，可独立选择宿主标题栏/歌词工具或完全自绘，不强制宿主底部播放栏 | 主题可提供Mini专属背景/装饰和完整内容布局         |
| 设置       | defaults、整体validate、设置组件、patch/reset          | 每个皮肤独立配置，页面和设置共享handle                                      | 同一主题下独立mini配置区域，由宿主持久化          |
| 停用/异常  | 保留选择意图和配置，临时回退；恢复后按仍有效的选择恢复 | 异常回退封面并重置选择，显式重选才重试                                      | 撤销当前主题Mini资源，恢复内置呈现                |
| 生命周期   | 只创建已选中/实际预览的资源                            | 只创建当前可见皮肤，切换释放旧页面上下文                                    | Mini未打开不创建，隐藏/退出销毁图形、媒体和子弹层 |

三者复用宿主现有PlaybackService、歌词模型/时间轴、ThemeStore完整字体与窗口控制，不各自创建播放器、队列、全局设置或时钟。完整播放页与Mini组件通过类型化上下文调用播放、收藏、面板与窗口命令，不读取私有QObject或接收裸Window句柄。

主题的surface/渐变/页面动效贡献会接入有作用域的视觉解析层；主题候选的样式只在该主题被选择或有效预览时注册。皮肤的局部样式只属于该皮肤实例scope，离页后撤销，不能留在全局。用户显式字体、透明度、磨砂和减少动效偏好不被主题defaults覆盖。

`ui.parts`中的`playback.page`和`mini.panel`提供完整公开正文的替换能力，可用于当前插件扩展；它们不代替主题中心/换肤抽屉中的候选、预览、验证和选择流程。布局/材质/动画仍使用Qt原生组件和宿主共享控件，未来主题/皮肤API不会通过修改内部组件路径实现。
