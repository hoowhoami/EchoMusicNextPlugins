# Folia 共享页面边界

本轮范围为一个 Folia 皮肤、十四种歌词样式及共享播放页面。必要的文本分词、完整字体、原生绘制、图片/字体导入、原生拖入及 ZIP 图层交换继续保留；模型分析、歌曲墙、额外队列命令、插件睡眠与额外选源恢复协议不在交付范围。

- 歌词、字幕、和声和背景使用宿主模型、只读 A/B 快照和真实 cue/呈现时钟，不复制可写播放状态。
- 胶囊直接呈现 native current，复用原有 typed 播放、进度、音量、模式、收藏和队列入口。
- 音频响应只取现有 audio.spectrum 的 bins/waveform；没有第二套 FFT、Beat This!/HTDemucs 模型或用频谱伪造鼓点结果。
- 十四种模式继续保留独立布局、歌词动效、现有频谱响应及可独立工作的背景/后处理；删除专用模型支路，不用空实现占位。
- 源码、许可和来源摘要按实际剩余生成输入保留。旧专属原件由最小快照收集器剔除，剩余原始字节不得格式化或改写。

精简后的统一宿主导出、完整安装、原生输入/资源退休与性能仍须复验；历史未完成项和新结果由 [任务清单](plan.md) 与 [验证记录](verification.md) 记录，不沿用旧包的扩展能力验收。
