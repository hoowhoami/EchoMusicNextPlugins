## 实现组织

2026-10-22 用户修正：采用一个插件包、一个 Folia 皮肤候选。仅调用一次 `ctx.ui.lyricsPage.registerSkin`，宿主换肤抽屉只出现 Folia；14 种样式在 Folia 播放页内部切换。一个 configuration 持久化当前 mode、共享偏好及按 mode 隔离的设置。注册不自动选择皮肤。

计划在 `plugins/folia-lyrics-skin/` 中按职责组织：

| 路径                                                | 职责                                                   |
| --------------------------------------------------- | ------------------------------------------------------ |
| `manifest.json`、`plugin.config.json`               | 必需能力、入口和受控打包资源                           |
| `src/entry.ts`、`src/styles.ts`                     | 仅注册 Folia；内部样式目录，不创建未选中的 UI          |
| `src/config.ts`                                     | 共享偏好、当前 mode 与按样式隔离的参数；完整 JSON 校验 |
| `qml/FoliaPage.qml`                                 | 共享播放页、背景、字幕、播放控制及正式面板入口         |
| `qml/shared/`                                       | 有界歌词窗口、字形布局、逐字绘制、呈现动画、共享设置行 |
| `qml/styles/<mode>/`                                | 一种样式的布局、运动、设置、shader 和专属绘制逻辑      |
| `qml/backgrounds/`                                  | 共享背景模式及配置；切换样式不重复创建背景             |
| `assets/previews/`、`assets/licenses/`              | 实测预览、逐项资产许可和来源记录                       |
| `LICENSE`、`THIRD_PARTY_NOTICES.md`、`README.md`    | 插件许可、上游署名、安装与作者说明                     |
| `tests/folia*.test.mjs`、`tests/types/authoring.ts` | 构建/配置/作者契约检查，不代替原生和视觉验收           |

该表包含当前文件和后续拟建文件，具体完成状态见下方清单。需要原生绘制原语时，先证明现有 SDK 不足，再在宿主补齐通用能力；不能在包内偷偷引入原生插件、浏览器或第二套播放器。
